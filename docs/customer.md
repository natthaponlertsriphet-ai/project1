ชนิดแฟ้มข้อมูล: Transaction File (Denormalized)
คำอธิบายแฟ้มข้อมูล: สำหรับบันทึกรายละเอียดของลูกค้าผู้เข้ามาใช้บริการในระบบจอง (ข้อมูลถูกฝังอยู่ในตาราง Bookings)
