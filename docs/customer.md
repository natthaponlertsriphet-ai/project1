แหล่งข้อมูล: D8
ชื่อแฟ้มข้อมูล: แฟ้มข้อมูลลูกค้า (Customer)
ชนิดแฟ้มข้อมูล: Master File / Transaction Data
คำอธิบายแฟ้มข้อมูล: สำหรับบันทึกรายละเอียดของลูกค้าผู้เข้ามาใช้บริการในระบบจอง

ตารางที่ 3.15 แสดง Data Dictionary ของแฟ้มข้อมูลลูกค้า

| ชื่อแอทริบิวต์ | ความหมาย | ชนิดข้อมูล | ขนาด (ไบต์) | รูปแบบ | รูปแบบช่วงข้อมูล | ป้อนข้อมูล (Y/N) | คีย์หลักหรือคีย์นอก | ตารางที่อ้างอิง |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `customer_id` | รหัสประจำตัวลูกค้า | Varchar(50) | 50 | x(50) | A-Z,0-9 | Y | PK | - |
| `customer_name` | ชื่อลูกค้าผู้ทำการจอง | Varchar(255) | 255 | x(255) | a-z,A-Z,ก-ฮ | Y | - | - |
| `customer_phone` | เบอร์โทรศัพท์ลูกค้า | Varchar(50) | 50 | x(50) | A-Z,0-9,a-z,+,\s,-,() | Y | - | - |
